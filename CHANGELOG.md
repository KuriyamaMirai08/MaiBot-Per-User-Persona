# Changelog

## 0.2.3 — Public source packaging

- Publish the isolated per-user engine, private administrator history page, and optional emoji bridge.
- Include the JSON selection fix: request-local JSON mode and disabled thinking, sufficient output budget, bounded regeneration, and strict single-index validation.
- Keep actual private profiles, databases, credentials, operational reports and deployment rollback scripts out of the repository.
- Default the public plugin to disabled. Add blank configuration examples and offline configuration preparation with explicit authorization and unlock.
- Add portable GPL helper fixtures, configuration tests, a public-content check, and Linux CI.

The public package is based on the deployed 0.2.3 behavior. Public-packaging additions do not replace or update any existing deployment automatically.
